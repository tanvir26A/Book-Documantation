# ৩০ নং পূর্ব ওয়ার্ড লাইব্রেরী — বই ডকুমেন্টেশন সিস্টেম

🔗 **লাইভ লিংক:** https://tanvir26a.github.io/Book-Documantation/

একটি সম্পূর্ণ ফাংশনাল, রিয়েল-টাইম লাইব্রেরী ম্যানেজমেন্ট ওয়েব অ্যাপ। বই, রিডার (সাথী/কর্মী/সমর্থক), বই ইস্যু-ফেরত এবং মাসিক রিপোর্ট — সবকিছু একটি মোবাইল-ফ্রেন্ডলি ইন্টারফেসে পরিচালনা করা যায়। ডাটা Firebase Realtime Database-এ সংরক্ষিত হয়, তাই যেকোনো ডিভাইস থেকে লিংকে ঢুকলেই একই ডাটা রিয়েল-টাইমে দেখা যাবে।

## বৈশিষ্ট্য

- 📚 বই যোগ, এডিট, মুছে ফেলা — কপি সংখ্যা অনুযায়ী প্রাপ্যতা ট্র্যাকিং
- 👤 রিডার যোগ, এডিট, মুছে ফেলা — ছবি, ফোন, ঠিকানাসহ
- 🏷️ রিডার টাইপ: সাথী / কর্মী / সমর্থক — টাইপ অনুযায়ী ফিল্টার
- 🕌 নামাজ কাযা ট্র্যাকিং (কর্মী-সাথী: ৩ মাসের হিসাব, সমর্থক: ১ সপ্তাহের হিসাব)
- ⏰ শেষ দেখা তারিখ ট্র্যাকিং — ৫ দিনের বেশি যোগাযোগ না হলে নাম লাল রঙে চিহ্নিত হয়
- 🔄 বই ইস্যু ও ফেরত — কপি না থাকলে ইস্যু বন্ধ থাকে
- 📊 মাসিক রিপোর্ট ড্যাশবোর্ড — কে কতগুলো বই পড়েছে, কোন বই কবে ইস্যু হয়েছে
- ⚡ রিয়েল-টাইম সিঙ্ক (Firebase Realtime Database) — একাধিক ডিভাইস থেকে একসাথে ব্যবহারযোগ্য

## ব্যবহৃত প্রযুক্তি

- HTML, CSS, Vanilla JavaScript (কোনো বিল্ড স্টেপ প্রয়োজন নেই)
- Firebase Realtime Database
- Font Awesome আইকন, Noto Sans Bengali ফন্ট
- GitHub Pages হোস্টিং

## সেটআপ (নিজে চালাতে চাইলে)

1. এই রিপোজিটরি ক্লোন করুন
2. `index.html` ফাইলের ভেতরে থাকা `firebaseConfig` অংশে নিজের Firebase প্রজেক্টের কনফিগ বসান
3. Firebase Console → Realtime Database → Rules-এ গিয়ে (টেস্টের জন্য) নিচের rules সেট করে Publish করুন:
   ```json
   {
     "rules": {
       ".read": true,
       ".write": true
     }
   }
   ```
4. GitHub Pages-এ হোস্ট করতে: Settings → Pages → Branch সিলেক্ট করে Save করুন

## ⚠️ গুরুত্বপূর্ণ নিরাপত্তা নোট

বর্তমান Rules (`.read: true, .write: true`) সবার জন্য খোলা — যে কেউ লিংক পেলে ডাটা দেখতে ও পরিবর্তন করতে পারবে। এটি টেস্টিং-এর জন্য ঠিক আছে, কিন্তু লাইভ ব্যবহারের ক্ষেত্রে Firebase Authentication যোগ করে Rules-এ `auth != null` চেক বসানো নিরাপদ।
